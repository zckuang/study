#git操作记录
git clone git@github.com:zckuang/study.git
#通过GitHub CLI生成认证密码，默认无需密码
 brew install gh
 gh auth login
然后会提示你选择：
 1. GitHub.com 还是 GitHub Enterprise → 选 GitHub.com
 2. Preferred protocol for git operations → 建议选 SSH（以后不用输密码）
 3. Generate a new SSH key → 选 Y（让 gh 帮你生成）
 4. Authenticate Git with your GitHub credentials → 选 Y
